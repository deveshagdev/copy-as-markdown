# Changelog

Each section's text becomes the GitHub release notes for that version.

## 1.0.1

- Fixed the page title being copied twice on pages that have a breadcrumb or
  byline above the main heading
- On pages the browser won't let extensions access, the popup now says so for
  any browser, not just Chrome, and recognises the Edge Add-ons store

## 1.0.0

First release.

- Copies the page, or your selection, as Markdown from the toolbar button, the
  right-click menu, or Alt+Shift+M
- Leaves out hidden content, navigation, forms and cookie banners
- Tables, code blocks with their language, absolute links and images
